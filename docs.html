Visão Geral

O que é este projeto?

Uma aplicação front-end completa, sem dependência de servidor, que permite ao usuário expressar como está sua disposição para interações sociais — de "Muito esgotado" até "No topo" — e acompanhar essa evolução ao longo do tempo com gráficos, histórico e personalização.

🎨

Visual Liquid Glass

Estética inspirada na identidade Apple com efeitos de vidro fosco, reflexos e transparências.

📊

Histórico e Gráfico

Registro persistente de estados com filtros, CRUD completo e gráfico de evolução semanal.

✨

Interatividade Rica

Emojis flutuantes com física de repulsão, drag & drop, confete, animações e tema claro/escuro.

📱

Responsivo e Acessível

Funciona em desktop e mobile, com suporte a mouse, toque e teclado (setas ← →).

Funcionalidades

O que o app faz

Cada funcionalidade foi projetada para tornar a experiência mais intuitiva e visualmente envolvente.

Slider Interativo

Arraste o ícone ⚡ para ajustar o estado. Funciona com mouse, toque (mobile) e teclado (← →). Um balão flutuante exibe o estado atual em tempo real.

Indicador de Bateria (Pilha)

Ícone estilo pilha com efeito glass que enche e esvazia dinamicamente conforme o nível selecionado, com cor e porcentagem correspondentes.

Barra de Estados Glass

Sete segmentos coloridos com reflexo de vidro (bolha Liquid Glass) que pulsam com animação CSS ao trocar de estado.

Botão Registrar

Salva o estado atual com data e hora no localStorage. O histórico é persistente entre sessões e acumula registros de todos os dias.

Histórico com CRUD

Lista completa de registros com ações de visualizar, editar e excluir individualmente, cada uma com modal Liquid Glass dedicado.

Filtros de Histórico

Filtre os registros por estado específico ou por data, com botão "Todos" para resetar os filtros rapidamente.

Gráfico Semanal

Linha de evolução dos últimos 7 dias com média diária de energia social, construído com Chart.js com gradiente e tooltip personalizado.

Tema Claro / Escuro

Alternância entre tema escuro (padrão) e claro com um clique, preferência salva no localStorage para persistir entre visitas.

Confete ao atingir "No topo"

Efeito visual de confete disparado automaticamente ao registrar o estado máximo de energia, usando a biblioteca canvas-confetti.

Badges de Contagem Diária

Contador de quantas vezes cada estado foi registrado hoje, exibido como badge na legenda para acompanhamento rápido.

Personalizar Estados

Modal com abas para editar nome, emoji e mensagem motivacional de cada estado. As alterações são salvas e refletem em toda a interface.

Emojis Flutuantes Interativos

Partículas de emoji no fundo com física de repulsão ao passar o mouse e drag & drop — pode arrastar e soltar para "brincar" com eles.

Arquitetura

Estrutura do projeto

Organizado em três camadas: HTML estrutural, CSS de estilos e JS dividido entre lógica principal e funcionalidades extras.

Project-Minha-Bateria-Social/ ├── index.html # Estrutura HTML + lógica JS principal ├── favicon.svg # Ícone do site (bateria estilo glass) ├── docs.html # Esta documentação ├── README.md # Documentação em Markdown ├── style/ │ └── style.css # Todos os estilos (Liquid Glass, animações, temas) └── js/ └── extras.js # Funcionalidades extras (tema, gráfico, confete, personalização…)

index.html — JS inline

  • Variáveis globais: estados, mensagens, cores
  • Função atualizar() — posicionamento do slider
  • Eventos: mouse, touch, teclado
  • CRUD do histórico (localStorage)
  • Modais: visualizar, editar, excluir
  • Canvas de emojis flutuantes
  • Drag & drop dos emojis
  • Migração de histórico legado

extras.js — funcionalidades adicionais

  • Tema claro / escuro
  • Confete ao atingir "No topo"
  • Gráfico semanal (Chart.js)
  • Badges de contagem diária
  • Filtros de histórico
  • Limpar histórico
  • Personalizar estados e mensagens
  • Hook aoRegistrar() chamado pelo inline

style.css — seções

  • BASE — body, gradiente de fundo
  • FUNDO — canvas, bolhas decorativas
  • CARD — efeito Liquid Glass
  • BARRA — segmentos + ::after glass
  • BATERIA — pilha estilo glass
  • HISTÓRICO — layout e CRUD
  • TEMA CLARO — overrides
  • GRÁFICO / PERSONALIZAR / FILTROS

localStorage — chaves

  • bateria_social_historico_v2
  • bateria_social_semanal
  • bateria_social_tema
  • bateria_social_estados
  • bateria_social_mensagens
  • bateria_social_historico (legado, migrado)
Como usar

Guia rápido de uso

O app foi projetado para ser intuitivo desde o primeiro acesso, sem necessidade de cadastro ou configuração.

1

Abra o app

Abra o arquivo index.html em qualquer navegador moderno. Não precisa de servidor ou instalação — funciona diretamente.

2

Selecione seu estado

Arraste o ⚡ pela barra colorida, clique num segmento ou use as setas do teclado. O balão flutuante mostra o estado em tempo real.

3

Registre o momento

Clique em ⚡ Registrar agora. O estado é salvo com data e hora e aparece imediatamente no histórico abaixo.

4

Acompanhe sua evolução

Veja o gráfico semanal ao final da página com a média diária dos últimos 7 dias. Filtre o histórico por estado ou data conforme precisar.

5

Personalize (opcional)

Clique em ⚙️ Personalizar para editar o nome, emoji e mensagem motivacional de cada estado de acordo com sua preferência.

Como executar localmente

# Opção 1 — Abertura direta (mais simples) Clique duplo em index.html → abre no navegador padrão # Opção 2 — XAMPP ou qualquer servidor estático Copie a pasta para htdocs/ Acesse: http://localhost/Project-Minha-Bateria-Social/ # Opção 3 — VS Code + Live Server Abra a pasta no VS Code Clique em "Go Live" na barra inferior
